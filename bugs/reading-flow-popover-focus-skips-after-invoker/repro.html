In each case, focus the "1" button with the keyboard (for example, click the "Start here" link and press Tab; in Safari, use Option+Tab instead of Tab) and press Enter to open the popover. Then press Tab four times, and then Shift+Tab until the focus leaves the popover backwards. The script under each case prints the focus order and two checks:

  • Tab from the "Close" button should move to the "link after the button" in the same paragraph.
  • Shift+Tab from the "inner link" (the first focusable element in the popover) should move to the "1" button.

Pass if both checks pass in the test and in the reference.
